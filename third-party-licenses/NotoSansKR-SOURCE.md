# Bundled Korean/Latin font

Noto Sans CJK KR Regular, unmodified upstream font, bundled for portable text rendering.
Local filename: `NotoSansKR-Regular.otf`. Internal project identifier: `Noto Sans KR`.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf
License: upstream `Sans/LICENSE`, copied alongside the font as `OFL.txt` (SIL OFL 1.1).

The static Regular font is intentional: the variable Google Fonts file defaults to
Thin in this Qt 5 environment. The same bundled static file renders text on both OSes.
