# RawBaker

> RAW · 일반 이미지를 원하는 형식으로 변환하는 무설치 데스크톱 프로그램
> **Digital Kiln — Processing & Perfection**

⚠️ **BETA Ver-0.1 (작업 중)** — Windows 10/11 64-bit.

## 주요 기능
- **다양한 확장자 자유 변환** — RAW(CR2/CR3/NEF/ARW/DNG/ORF/RW2/RAF) · 일반(JPG/PNG/TIFF/WebP/BMP) ↔ JPEG/PNG/TIFF/WebP/BMP
- **자동 밝기 보정** — RAW를 그냥 변환해도 어둡지 않게 (기본 ON, 끌 수 있음)
- **간단 보정 5종** — 노출 · 대비 · 색온도 · 채도 · 선명도 (프리셋 저장/불러오기)
- **크롭** — 비율 드롭다운(자유/1:1/4:3/3:2/16:9/원본) + 정밀 픽셀, 중앙 박스 드래그
- **리사이즈(%) · DPI · EXIF 처리 · 파일명 접미사 · 충돌 처리 · 폴더 일괄 변환**
- 다크 테마 UI · 한국어

## 다운로드

## 사용법
1. `RawBaker.exe` 실행
2. 변환할 파일이나 폴더를 끌어다 놓기
3. 저장 형식·보정·크롭을 고르고 **변환**
