# UI fonts

Rajdhani Bold: https://github.com/google/fonts/tree/main/ofl/rajdhani — SIL OFL 1.1 (Rajdhani-OFL.txt).
Pretendard Regular/Medium/Bold: https://github.com/orioncactus/pretendard — SIL OFL 1.1 (Pretendard-OFL.txt). Unmodified static TTFs.

These fonts are bundled for offline UI use. Noto Sans CJK KR remains the document rendering font for existing project compatibility.
